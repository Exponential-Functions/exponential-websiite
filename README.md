# Exponential Fucntions

A luxurious, deep-tech corporate ecosystem landing workspace for **Exponential Fucntions** and its two core sub-brands:
- **Exponential Labs**: Advanced machine intelligence research, private sovereign inference stacks, and LLM orchestration.
- **Exponential Marketing Agency**: Intelligent creative automation, autonomous brand workflows, and signal-drift analytics.

Designed with a focus on high-fidelity motion graphics, interactive SVG topological state-graphs, responsive typography, and adaptive brand shifting (Core Slate, Cyber Emerald, and Warm Sand).

## 🪐 Core Architecture

- **Engine**: [Astro](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Style System**: Structured Vanilla CSS utilizing custom HSL color-mixing grids
- **Graphics & Vectors**: Inline SVG topologies featuring dynamic canvas line-marching and node inspectors
- **Responsive Layout**: Fluid flex/grid structures adapting to viewport bounds, with a floating tab switcher for touch screens

## 🛠️ Development Operations

Ensure Node.js is active within your environment, then execute:

```bash
# Initialize dependency systems
npm install

# Start local neural dev server
npm run dev

# Compile distribution build assets
npm run build

# Preview production target locally
npm run preview
```
